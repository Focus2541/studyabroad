# StudyAbroad — เตรียมตัวไปเรียนภาษา 1 ปี

เว็บแอป (PWA) ภาษาไทย ช่วยเตรียมตัวและใช้ชีวิตตอนไปเรียนภาษาที่ ออสเตรเลีย นิวซีแลนด์ หรือแคนาดา
ติดตั้งเป็นแอปบน Android ได้ ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่องเท่านั้น

## ฟีเจอร์
1. **ไทม์ไลน์ก่อนไป** — นับถอยหลังจากวันเดินทาง งานแยกตามประเทศและประเภทวีซ่า (นักเรียน / Working Holiday) เปลี่ยนวันที่และเพิ่มงานเองได้
2. **เอกสาร** — เก็บรูป/PDF พาสปอร์ต วีซ่า เอกสารโรงเรียน ประกัน วุฒิ (IndexedDB) เตือนก่อนหมดอายุ (พาสปอร์ต 210 วัน อื่นๆ 60 วัน)
3. **งบทั้งปี** — ค่าเรียน ที่พัก ค่าครองชีพรายเดือน แปลงสกุลเงินอัตโนมัติ บันทึกรายจ่าย/รายรับจริง บอกว่าเงินพอถึงเดือนไหน และเทียบงบกับที่ใช้จริง
4. **เช็กลิสต์หลังไปถึง** — ตามกฎของแต่ละประเทศ (TFN/IRD/SIN ธนาคาร ซิม ประกัน แจ้งที่อยู่)
5. **ชีวิตประจำวัน** — ตารางเรียนรายสัปดาห์ วันหยุด/ปิดเทอม ทริป (ค่าทริปรวมเข้าแผนงบ)
6. **การ์ดฉุกเฉินออฟไลน์** — เบอร์ฉุกเฉิน สถานทูต/สถานกงสุลไทย ข้อมูลประกัน ผู้ติดต่อ ประโยคขอความช่วยเหลือ
7. **กฎที่นักเรียนต่างชาติต้องรู้** — ชั่วโมงทำงาน การแจ้งย้ายที่อยู่ การต่อวีซ่า ข้อห้าม พร้อมลิงก์เว็บทางการ
8. **งานพิเศษ** — บันทึกกะทำงาน นับชั่วโมงตามกฎวีซ่า (ออสเตรเลีย 48 ชม./2 สัปดาห์ นับทุกช่วงที่เริ่มวันจันทร์ · นิวซีแลนด์ 25 ชม./สัปดาห์) ไม่นับช่วงปิดเทอม เตือนก่อนเกิน และเตือนเมื่อใกล้ครบระยะเวลาต่อนายจ้าง (Working Holiday)
9. **รายได้อัตโนมัติ** — ค่าแรงขั้นต่ำ × ชั่วโมงที่วางแผน − ภาษี เข้าแผนงบ
10. **เทียบโรงเรียน** — ค่าเรียน ค่าแรกเข้า ปิดเทอม สิทธิ์ทำงาน แล้วกด "ใช้โรงเรียนนี้" เข้าแผนงบ
11. **หาห้อง** — เช็กลิสต์ก่อนจ่ายมัดจำ สัญญาณมิจฉาชีพ เทียบห้องและนำค่าเช่าเข้าแผนงบ
12. **อัตราแลกเปลี่ยน** — แปลงเงิน กราฟย้อนหลัง 6 เดือน (ECB/Frankfurter) เรทเป้าหมาย และเงินที่ต้องแลกตามแผน
13. **แจ้งเตือน LINE** — Apps Script + LINE OA เตือนทุกเช้า ดู [line-reminder/README.md](line-reminder/README.md)
14. **ข้อควรระวัง & ข้อควรรู้** — มิจฉาชีพแอบอ้างหน่วยงานรัฐ สิทธิ์แรงงาน เงินคืนตอนกลับ (ภาษี, Superannuation/DASP) ความปลอดภัย กฎหมาย/มารยาท สายด่วนสุขภาพจิต
15. **อากาศ ปลั๊กไฟ การเดินทาง** (จาก TripBudget) — บอกว่าแต่ละฤดูคุณอยู่กี่เดือน และของที่ควรเตรียม
16. **ของจำเป็นสำหรับอยู่ 1 ปี** — เช็กลิสต์ เอกสาร เงิน อุปกรณ์ สุขภาพ เสื้อผ้าตามฤดูที่อยู่จริง
17. **ไทม์ไลน์ก่อนกลับ** — แจ้งย้ายออก ขอเงินมัดจำ ยื่นภาษี ขอ Super คืน ปิดบัญชี
- เทียบ 3 ประเทศ · ส่งออกปฏิทิน .ics (Google Calendar) · สำรอง/กู้คืน .json (รวมไฟล์เอกสาร) และเตือนเมื่อไม่ได้สำรองเกิน 14 วัน

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปทั้งหมด |
| `countries.js` | ข้อมูลประเทศ กฎ ตัวเลข ไทม์ไลน์ เช็กลิสต์ สถานทูต — แก้ไฟล์นี้เมื่อกฎเปลี่ยน |
| `sw.js` | ทำให้ใช้ออฟไลน์ได้ — **เปลี่ยนเลข `CACHE` ทุกครั้งที่แก้ไฟล์อื่น** |
| `manifest.json`, `icon.svg`, `icon-192.png`, `icon-512.png` | ติดตั้งเป็นแอป |
| `line-reminder/` | Apps Script สำหรับแจ้งเตือน LINE + คู่มือ |

## อัปเดตข้อมูล
ข้อมูลกฎ/ตัวเลขค้น ณ วันที่ใน `DATA_AS_OF` (countries.js) กฎวีซ่าและค่าครองชีพเปลี่ยนบ่อย
ตรวจลิงก์ทางการก่อนยื่นจริงทุกครั้ง แล้วแก้ค่าใน `countries.js` + เปลี่ยน `DATA_AS_OF` + เปลี่ยน `CACHE` ใน `sw.js`

## โฮสต์บน GitHub Pages
1. สร้าง repo `studyabroad` แล้วอัปโหลดไฟล์ทั้งหมด
2. Settings › Pages › Deploy from a branch › `main` / root
3. เปิด `https://<username>.github.io/studyabroad/` บนมือถือ › เมนู ⋮ › ติดตั้งแอป
