# แจ้งเตือน StudyAbroad ผ่าน LINE

ระบบส่งข้อความ LINE ทุกเช้า 08:00 เมื่อมีงานในไทม์ไลน์ใกล้ถึงกำหนด เอกสารใกล้หมดอายุ วันเดินทางใกล้มาถึง หรือเรทเงินถึงเป้าหมาย
ใช้ Google Apps Script (ฟรี) + LINE Official Account (แพ็กเกจฟรีส่งได้ 200 ข้อความ/เดือน ระบบนี้ส่งไม่เกินวันละ 1 ข้อความ)

## ข้อมูลที่ส่งออกจากเครื่อง
ส่งไป Google Sheet ของคุณเอง: ชื่องานในไทม์ไลน์ + วันที่ · ชื่อเอกสาร + วันหมดอายุ · วันเดินทาง/วันกลับ · วันหยุด/ทริป · เรทเป้าหมาย
**ไม่ส่ง** ไฟล์เอกสาร ยอดเงิน รายจ่าย หรือข้อมูลการ์ดฉุกเฉิน

## ขั้นที่ 1 — สร้าง LINE Official Account + Messaging API
1. ไปที่ https://developers.line.biz › Log in › สร้าง Provider
2. สร้าง channel แบบ **Messaging API** (ระบบจะให้สร้าง LINE Official Account ไปด้วย)
3. แท็บ **Basic settings** › คัดลอก **Your user ID** (ขึ้นต้นด้วย `U`)
4. แท็บ **Messaging API** › **Channel access token (long-lived)** › Issue › คัดลอก
5. สแกน QR ในแท็บ Messaging API เพื่อเพิ่มบอทเป็นเพื่อน (ถ้าไม่เพิ่มเพื่อน จะส่งข้อความไม่ได้)

## ขั้นที่ 2 — Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ `StudyAbroad LINE`
2. ส่วนขยาย › **Apps Script** › ลบโค้ดเดิม › วางโค้ดจาก [`Code.gs`](Code.gs) › บันทึก
3. ⚙️ การตั้งค่าโปรเจกต์ › **Script properties** › เพิ่ม 3 ค่า:
   | Property | ค่า |
   |---|---|
   | `LINE_TOKEN` | Channel access token จากขั้นที่ 1.4 |
   | `LINE_USER_ID` | Your user ID จากขั้นที่ 1.3 |
   | `SECRET` | ตั้งรหัสลับเอง เช่น ตัวอักษรสุ่ม 20 ตัว |
4. เลือกฟังก์ชัน `setup` › กด **Run** › อนุญาตสิทธิ์ › ควรได้ข้อความ "ตั้งค่า… เรียบร้อย" ใน LINE
5. **Deploy › New deployment** › ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (จำเป็นเพื่อให้แอปส่งข้อมูลเข้ามาได้ — มีรหัสลับ SECRET ป้องกันคนอื่นอยู่แล้ว)
6. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 3 — ตั้งค่าในแอป
1. แอป StudyAbroad › เมนู ☰ › **🔔 แจ้งเตือนผ่าน LINE**
2. ใส่ Web App URL และรหัสลับ › ติ๊ก "ซิงก์อัตโนมัติ" › บันทึก
3. กด **ส่งข้อความทดสอบ** → ควรได้ข้อความใน LINE
4. กด **ซิงก์ตอนนี้** ครั้งแรก หลังจากนั้นแอปจะซิงก์เองเมื่อข้อมูลเปลี่ยนและมีเน็ต

## ปรับแต่ง
- เปลี่ยนเวลาส่ง: แก้ `SEND_HOUR` ใน Code.gs แล้วรัน `setup()` อีกครั้ง
- เปลี่ยนจำนวนวันที่เตือนล่วงหน้า: แก้ `LEAD`
- ถ้าแก้ Code.gs หลัง Deploy แล้ว: Deploy › Manage deployments › แก้ไข › Version: New version (URL เดิมใช้ต่อได้)

## แก้ปัญหา
- **ไม่ได้ข้อความทดสอบ:** ตรวจว่าเพิ่มบอทเป็นเพื่อนแล้ว และ SECRET ตรงกัน ดู log ได้ที่ Apps Script › Executions
- **ซิงก์แล้วไม่เตือน:** เปิด Sheet ดูว่ามีแท็บ `items` และมีรายการ · เตือนเฉพาะวันที่ตรงกับจำนวนวันใน `LEAD`
